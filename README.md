# 信息茧房 · 算法对公众认知的无声谋杀

一份十页的悬疑案卷式演示稿，讲推荐算法如何把公众认知收窄成一条缝。

**在线放映：<https://wren-106.github.io/Assesgment4/>**

## 怎么用

| 操作 | 效果 |
| --- | --- |
| `→` / `←` / 空格 | 翻页；页内有分步时先逐拍推进 |
| `P` 或点右下角控制条 | 开始 / 停止自动演播 |
| `?play`（如 `.../Assesgment4/?play`） | 打开即自动放映 |
| `Esc` / `O` | 总览全部页面 |
| `F` | 全屏 |

自动演播放完一拍会停 1.1 秒，10 页全程约 1 分 40 秒。按任意翻页键会立刻接管，不与讲解抢页。

## 文件

- `index.html` — 放映主稿（reveal.js + GSAP，页面级转场与元素级动画）
- `art/` — 图片素材
- `vendor/` — reveal.js / GSAP / 主题与配色，均已本地化
- `deck.pptx` — 可编辑的 PowerPoint 版本（10 页，含原生动画与转场）

## 技术说明

纯静态，无构建步骤，无外部网络请求（字体走本机宋体 / Noto Serif SC 回退），断网也能放映。

`deck.pptx` 与网页稿同源导出。网页稿有而 PowerPoint 里做不到的效果已在导出时降级：满版图横摇、墨晕洇出、点阵分批亮起这三类。PPTX 也没有内建自动放映，需要时用 PowerPoint 的「排练计时」录一遍。
